# Support

Use public issues for reproducible bugs and feature proposals. Include the
version from `release/VERSION`, `release/EXPORT-ID`, host implementation, exact
command, expected behavior, and observed behavior. Use the private path in
`SECURITY.md` for vulnerabilities.

This is pre-1.0 software. Compatibility is documented and tested, but support is
provided on a best-effort basis and no response-time commitment is implied.
